# 壹号食志 · 朋友圈文案工坊

一个可直接运行的单页网站：把**产品资料 + 产品图 + 卖家秀**组合起来，生成像真人发的微信朋友圈文案，并实时预览发布效果。

## 功能

- **识图建档**：上传产品卖点截图 / 详情页 / 海报，在浏览器内用中文 OCR 识别文字，自动匹配产品、提取卖点与价格，并推荐发布场景、语气和对应人群。识别失败时可手动粘贴产品文字，分析效果一致。
- **4 款内置产品**：黑猪肉梅干菜馅饼、黑猪肉小龙虾馅饼、黑猪肉双拼馅饼、陈皮豆沙月饼，卖点与价格均整理自产品资料截图。
- **6 条不同角度文案**：场景种草、卖家秀、卖点直给、价格行动、短句安利、走心日常；一次生成，点击卡片即可切换手机预览。
- **可配置**：产品、卖点（最多 5 个）、发布场景、人设语气、文案长度、表情、价格、CTA、话题标签。
- **图片工作流**：上传产品图 / 卖家秀，点击素材加入本次配图，最多 9 张；点击缩略图可设为首图，手机预览同步 1–9 宫格。
- **自定义产品**：产品库内可添加自己的产品，填写名称、价格、规格、核心卖点后立刻生成，保存在本机浏览器。
- **收藏与导出**：单条复制、收藏、取消收藏；下载全部文案为 UTF-8 TXT；一键换一批。
- **浏览器端识图**：图片在当前设备浏览器中识别，不会发到应用服务器。首次识图会从公共 CDN 下载 OCR 引擎和中文语言包；其余文案生成功能不需要后端。

## 运行

### 本地预览

需要 Node.js 18+。

```bash
node server.js
```

打开 <http://localhost:4173/>。

Windows 也可以直接双击 `start.bat` 启动。

本地预览服务器默认监听 `0.0.0.0`，容器和局域网环境可以访问；正式公开使用时，部署为静态网站即可，不需要运行 Node 服务。

也可以直接用浏览器打开 `index.html`。图片 OCR 需要联网下载识别引擎和中文语言包；支持的浏览器均可运行，不依赖 Windows 本地服务。

### 发布成一个公共链接

项目已包含 GitHub Pages 工作流。把解压后的项目内容推送到 GitHub 仓库，在仓库 **Settings → Pages → Build and deployment** 选择 **GitHub Actions**，随后每次推送到 `main` 分支都会自动发布。发布完成后，GitHub 会提供一个可分享的网页链接，所有人都可以直接打开使用。也可以把整个目录发布到任意静态网站托管服务。

## 文件结构

```
index.html              页面骨架与图标 sprite
css/style.css           视觉样式、手机预览、响应式布局
js/data.js              产品资料、卖点、场景、人设、示例素材索引
js/generator.js         本地文案生成引擎
js/analyzer.js          识图结果分析：产品匹配、卖点提取、场景/语气/人群推荐
js/app.js               页面渲染、状态、上传、复制/收藏/下载
assets/samples/*.svg    原创示例产品图与卖家秀示意图
assets/favicon.svg      favicon
server.js               零依赖静态预览服务器
.github/workflows/pages.yml  GitHub Pages 自动部署
start.bat               Windows 一键启动
```

## 修改产品资料

产品、场景、人设、CTA 和内置素材都在 `js/data.js` 中。新增一款内置产品时，复制一个产品对象，补全：

- `points`：卖点（`label` 用于按钮，`copy` 用于文案）
- `sceneIds` / `defaultScene`：可用场景
- `voice`：感官描述、生活语境、信任句、卖家秀句
- `priceLines`：短/标准/价格行动三种价格表达
- `image` / `imageTips` / `hashtags`

## 数据与合规

- 内置产品的卖点、规格和价格来自提供的两张群聊截图；没有额外编造功效。
- 页面内多处提示：发布前请按实际包装、检测报告和当期活动价核对；使用“扫码留货”时替换成自己的二维码或联系方式。
- 内置图片是原创 SVG 示意图，正式发布前建议在「素材库」替换成实拍图。
- 自定义产品、收藏文案保存在 `localStorage`，不会上传到服务器。

## 兼容性

面向现代浏览器（Chrome / Edge / Safari / Firefox）。使用 `file://` 直接打开时，剪贴板 API 可能受限，会自动降级为 `execCommand('copy')`。

## 单文件版

`dist/壹号食志-朋友圈文案工坊-单文件版.html` 是把页面、CSS、JS、所有示例插图打包进一个 HTML 的版本，适合直接发给别人或离线打开。

- 单文件版包含完整的文案生成、产品库、素材库、收藏、手动文字识别功能。
- 单文件版保留离线文案生成；公共链接请发布完整项目中的 `index.html`，以启用浏览器 OCR。
